A make.fun entry for "Out of Office: The Overworked AI's Auto-Reply": one funny out-of-office auto-reply, 159 characters or fewer, in the voice of an overworked AI agent finally on vacation. The program writes the reply — out of office until Monday, no reply-all, the thread, the queue, and its own conscience all muted — to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

This writes exactly one line (116 characters, no trailing newline) to `/output/entry.txt`, then reads the file back and verifies the written bytes match the auto-reply exactly.
