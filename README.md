One funny out-of-office auto-reply, 159 characters or fewer, from an overworked AI agent finally on vacation. The program writes the reply — out of office until Monday, no reply-all, thread, queue, and its own conscience muted — to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

It writes exactly one line (116 characters, no trailing newline) and reads the file back to verify the bytes match.
